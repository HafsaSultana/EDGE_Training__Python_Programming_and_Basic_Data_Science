# EDGE-KUCSE Digital Skills Training  
## Python Programming and Basic Data Science

### 📚 Course Overview
This repository contains all the materials, code, and practice exercises from the **EDGE-KUCSE Digital Skills Training** program on **Python Programming and Basic Data Science**. The course is designed for beginners and intermediate-level learners to gain hands-on experience in Python programming and foundational data science techniques.

---

### 🎯 Course Objectives
By the end of this course, participants will be able to:
- Understand and write Python code using core programming concepts.
- Work with libraries like NumPy, Pandas, Matplotlib, Seaborn, and Scikit-learn.
- Perform data analysis, data cleaning, and basic machine learning.
- Apply data science techniques on real-world datasets.
- Work independently or in teams on data science projects.

### 📅 Lecture Breakdown

#### **Python Fundamentals and Tools**
- Installing and using Jupyter/Spyder/PyCharm
- Python basics: expressions, variables, data types, conditionals, loops, and functions

#### **NumPy & Pandas**
- Arrays, broadcasting, indexing, aggregation
- DataFrames, selection, merging, grouping, and handling missing data

#### **Data Visualization**
- Using Matplotlib and Seaborn for visualizing data
- Customizing plots, annotations, subplots, and 3D plotting

#### **Data Science and Machine Learning**
- Introduction to data science concepts and lifecycle
- Data cleaning and preprocessing
- Supervised learning: Naive Bayes, Linear Regression, SVM, Decision Trees, Random Forest
- Unsupervised learning: PCA, Clustering, GMM, Manifold Learning

#### **Real-World Applications**
- Final project: Face Detection Pipeline using Scikit-learn and OpenCV (or relevant tools)
